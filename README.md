# Analizador de Chats Claude

Analiza tus conversaciones de Claude AI de forma 100% privada. Todo corre en tu navegador, nada se sube a internet.

## Privacidad

- **Sin servidor** — No hay backend ni API. Todo es JavaScript local.
- **Sin red** — Funciona offline. Puedes desconectar internet.
- **Sin tracking** — No hay analytics, cookies de terceros, ni telemetria.
- **Datos locales** — Todo se guarda en localStorage de tu navegador.
- **Borrado total** — Un boton elimina todo de tu maquina.

## Que analiza

- **Tecnologias** — Detecta 50+ lenguajes, frameworks y herramientas mencionados
- **Temas** — Clasifica conversaciones por area (web, datos, IA, seguridad, etc.)
- **Proyectos** — Identifica proyectos mencionados en tus chats
- **Patrones** — Tipo de consultas (codigo, debug, explicacion, diseno)
- **Estadisticas** — Palabras, mensajes, insights de uso

## Uso

1. Abre `index.html` en tu navegador (o visita la GitHub Pages)
2. Pega tus conversaciones de Claude en "Cargar Chats"
3. Ve a "Procesar" y ejecuta el analisis
4. Revisa resultados y exporta en JSON o CSV

## Despliegue en GitHub Pages

1. Ve a Settings > Pages en tu repositorio
2. Selecciona la rama `main` y carpeta `/ (root)`
3. Tu app estara en `https://tuusuario.github.io/claude/`
